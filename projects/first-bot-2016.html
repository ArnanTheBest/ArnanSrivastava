First bot, 2016

My first robot ever, built with almost no prior experience - and only ever built in CAD, never actually fabricated. It shows: the intake was broken, the electronics placement was genuinely bad, and the chassis had no rigidity. As designed, this robot would not have worked in real life. The one real success was the swerve modules, built specifically to handle rough terrain for that year's terrain-heavy game. Kept here as the starting point everything else was built on.
